## 📌 Project Overview

The **Number Guesser Game** is an interactive game developed as part of my **Software Development Internship at SkillCraft Technology**.

The application challenges users to guess a randomly generated secret number within a specified range. After every attempt, the game provides feedback to help users determine whether their guess is higher or lower than the target number.

The project focuses on implementing programming fundamentals, logical reasoning, conditional statements, random number generation, and user interaction.

## 🎯 Project Objectives

- Develop an interactive number guessing game.
- Implement random number generation.
- Create an engaging user experience.
- Apply conditional statements and logical operations.
- Provide feedback based on user guesses.
- Strengthen programming and problem-solving skills.

## ✨ Key Features

- 🎲 **Random Number Generation:** Generates a secret number for the user to guess.
- 🔢 **User Input:** Allows players to enter their guesses.
- 💡 **Instant Feedback:** Indicates whether the entered number is too high or too low.
- 🎯 **Correct Guess Detection:** Identifies when the player guesses the correct number.
- 🔄 **Replay Functionality:** Allows users to play multiple rounds, if implemented.
- ⚡ **Interactive Gameplay:** Provides a simple and engaging gaming experience.

## ⚙️ How to Play

1. Start the Number Guesser Game.
2. The application generates a random secret number.
3. Enter your guess within the specified range.
4. The game provides feedback:
   - **Too High:** Your guess is greater than the secret number.
   - **Too Low:** Your guess is smaller than the secret number.
   - **Correct:** You successfully guessed the secret number!
5. Continue guessing until you find the correct number.
